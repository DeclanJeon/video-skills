## 4. 권장 설계 범위

**추천: A와 B를 기존 설명 모션 설계의 추가 검토 범위로만 묶는다.** C는 조건부 참고 후보로 남긴다. 새 스킬/라우팅/원장/스키마/실행기/의존성을 만들지 않는다.

후속 승인 시 기존 `docs/superpowers/specs/2026-11-27-episode-handoff-motion-design.md`의 모션 범위와 중복 조정한다. 시작/종료/시간 계약을 재작성하지 않고, 중심/보조의 시선 위계와 관계 공개 순서의 누락만 검증한다. 이미 승인된 회차 연결·편집 복구 범위를 덮어쓰지 않는다.

순서: 기존 지침으로 동일 합성 입력 판단 → 실제 누락 판정 → 담당 정본 한 곳에 최소 보강 → 같은 입력/비대상 입력 재검사. 필요한 실제 렌더나 에이전트 위임·독립 검수는 그 작업의 명시 승인과 이용 가능한 도구 범위에서 별도로 진행한다.

현재 상태는 **source-observed / proposal**, 효과 검증/실제 생성 PASS가 아니다. 본 재조사는 실제 실행 스킬을 수정하지 않았다.
