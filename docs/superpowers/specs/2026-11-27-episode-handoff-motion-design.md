# 연재 회차 연결과 설명 모션 — 승인 설계 (2026-11-27)

목표: 다음 회차 작가와 컷 편집자가 선행 사실이나 타이밍을 추측하지 않아도 되게 한다. 적용 여부는 영상 길이가 아니라 이야기의 의존 관계와 모션의 전달 기능으로 판단한다.

## 선택과 범위
- 채택: 기존 프리프로덕션 story-writer와 film-editor 지침에서만 조건부로 보강. 하나의 문제에 담당자 하나, 기존 PLT·편집 레이어 사용.
- 보류: 실제 데이터 기반 그래프 샷. 축척·누락값·출처 검증을 별도로 설계해야 한다.
- 제외: 새 스킬·원장·필수 템플릿 필드, 루트 라우팅, 프로·포스트 실행, 외부 도구 설치·비용·게시.

## 담당별 계약
- story-writer: 앞 회차 사건이 다음 회차의 원인이면 PLT의 해당 회차 끝에서 이번에 해결된 일, 다음 회차로 이어지는 구체적 사실(예: 인물의 지식 또는 소지품), 아직 회수되지 않은 복선을 구분한다. 다음 회차 첫 장면을 직전 결과와 비교한다. 같은 상태를 다시 쓰거나 없는 복선을 만들지 않는다. 독립 단편·독립 에피소드에는 별도 항목이 없다.
- film-editor: 자막·도형·그래픽 움직임이 의미를 전달할 때만 P3의 해당 편집 레이어에 시작 신호, 대상과 변화, 지속시간, 종료 상태를 적는다. 예: ‘단 하나’ 발화 시작에 밑줄이 왼쪽부터 0.3초간 그어져 문장 끝까지 유지. 기획한 지속시간과 실제 발화 시각을 구분한다. 일반 대화 컷의 기존 진입/이탈·홀드 규칙은 유지한다.

## 수용 기준
수정 전에 현재 지침으로 동일 입력을 시험한다. 회차 사이 지식 오류를 찾는지, 모션의 시작과 종료를 재현할 수 있는지, 비대상 컷/작품에 불필요한 양식을 요구하지 않는지 비교한다. 이미 통과하는 담당 지침은 변경하지 않는다. 문서 시험은 영상 품질이나 실제 렌더 검증으로 간주하지 않는다.
