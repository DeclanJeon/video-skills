## 수락 경계

후보는 사례로 증명된 차이만 반영한다. 근거가 부족한 요청은 unverified, 실제 작업물 없는 설계 예시는 예시로 표시한다. 최종 검증은 15초 제품 공개 패킷(정보·조명·참조·실물 판단), 동일 사례 전후 비교, 관련 테스트, 현재 변경 해시에 대한 독립 검수다. 특정 클립의 번호나 가격을 공통 규칙으로 쓰지 않는다. 기존 무관한 변경, 상위 라우터, 원장, 스키마, 실행·권리 게이트, 외부 서비스에는 손대지 않는다.
