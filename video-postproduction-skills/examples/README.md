# 예시와 검증 범위

이 JSON들은 형식 예시이며 실제 source/편집/설치/권리 승인이 아니다. source와 핀이 실제 current intake에 없으면 실행은 거절된다. 빈 install authority는 `awaiting_consent`이고 질문을 했다는 기록도 아니다.

실행 중인 환경·CLI 인자는 `python3 scripts/postproduction.py --help`를 조회한다. 로컬 intake는 `python3 scripts/postproduction.py intake PROJECT.json --request request.json`, 다음 작업은 승인된 실제 WorkOrder의 prepare/run/observe다.

실제 native fixture 증거는 프로젝트 내부 `qa/native-probes-01/`과 `qa/implementation/`에 있다. 그 media는 synthetic 기술 시험이며 실제 인간 시청/청취/작품/벤더 신규 설치 성공이 아니다. 세 native 프로그램의 실제 산출물과 installer contract stub을 섞지 않는다. 공개 배포/글로벌 skill 등록은 이 로컬 구현에 포함되지 않는다.
