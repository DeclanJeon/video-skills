# 피니싱 실행

## 입력
현재 full-picture/실제 RGBA plate/text/WAV mix artifact IDs, FinishingRecipe/profile, receiver/필수 deliverables/권리. [공통 실행 계약](../references/execution-contract.md)을 먼저 읽는다. 분야 변경안은 총괄의 정본 commit으로 반영한다.

## 절차
1. 시스템·동일 프로그램/필수 dependency를 먼저 점검해 적합한 설치를 재사용한다. 새 설정·폰트·프로그램은 정확한 계획을 실제 사용자에게 질문하고 명시 동의 후 설치한다. 동의 전 download/installer를 실행하지 않는다.
2. 정본의 실제 consumed producer lineage와 source/approval/recipe/native/sidecar 핀을 대조한다. profile만 보고 템플릿이나 없는 mix를 추측하지 않는다.
3. FilmCraft actual movie/still/WAV resource IDs를 관측해 frame/tick/sample을 맞춘다. still nominal duration/rate를 source-video handle 인증으로 바꾸지 않는다.
4. 현재 native projection/readback/export와 독립 full video/audio decode·waveform/format·alpha/pixel 기술 검사를 수행한다. 부분 출력/offline/수동 수정은 reimport·관측이 필요하다.
5. 정확한 최종 파일 QA와 receiver·권리를 받아 로컬 no-clobber bundle을 만든다. editable은 native/media relink·font dependency/재배포와 실제 세 앱 reopen을 확인한다. master/variant/fixture/reported를 구별한다.

## 반환
actual saved/rendered/materialized/current, 전체 input→output/clip map, native/editable/mix inventory·checksum·손실/dependency 지침과 열린 QA/납품 조치. export는 작품/게시 완료가 아니다.
