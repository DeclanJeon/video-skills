# 전환 준비 — 현재 설치 금지

v2는 아직 개발 중이다. WO-13의 종단 평가와 사용자 전환 승인이 모두 있어야 활성 경로 변경, 링크 생성 또는 버전 변경이 가능하다. `cutover_preflight.py`는 읽기 전용이며 종료 0도 설치 승인이 아니다.

## 현 상태 확인

패키지 루트에서:

```sh
python3 scripts/check_skills.py --json
python3 scripts/cutover_preflight.py --target "$HOME/.pi/agent/skills" \
  --equipment codex-imagen --equipment higgsfield-generate --equipment blender-previsualization
```

Codex 대상이라면 실제 등록 경로(기본 후보 `~/.codex/skills/`)를 `--target`에 지정한다. `--equipment`는 사용하려는 장비만 열거한다. 검색 경로의 파일 존재만 검사하며 등록·호출·인증·모델 지원은 검증하지 않는다. 이미 다른 폴더나 끊긴 링크가 같은 이름을 쓰면 이름을 비우거나 덮어쓰지 말고 별도 결정을 받는다.

## 승인 이후 전환·롤백 계획

1. 활성 스킬 경로와 기존 워크플로 지시의 스냅샷을 기록한다. 현재 v1 링크는 그대로 둔다.
2. 승인된 v2 스냅샷의 20개 스킬 디렉터리를 원래 패키지 루트를 유지하는 방식으로 등록한다. 승인된 새 링크 목록과 실제 대상을 기록한다. 기존 링크는 덮어쓰지 않는다.
3. 새 세션에서 감독과 지정 크루가 유일하게 잡히는지 읽기 전용으로 확인한다. 이 확인 뒤에만 사용자 승인 내용에 따라 기본 경로를 전환한다.
4. 롤백 시 이번 전환이 생성했고 대상이 변하지 않은 링크만 제거하고, 활성 지시를 전환 전 스냅샷으로 원복한다. v1 경로를 새 세션에서 확인하고 프로젝트·설계 기록·v2 원본은 보존한다.

위 순서는 제안이다. 이번 작업에서 사용자 경로에 링크를 생성하거나 설정을 변경하지 않았다.
