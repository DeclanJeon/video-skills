# CTY — 작성 양식

이 문서는 양식이다. 예시·미정 값은 정본으로 등록하지 않는다.

## 축

컷 / 화면 좌우·시선 / 축 이탈·리셋

## Snn-Cnn

컷마다 이 블록을 복제하고 실제 컷 ID로 바꾼다. [연결 계약 정본](../../docs/design/05-conti-collaboration.md#4-연속성-원장-cty)을 따른다. 아래 값은 작성 슬롯이며 정본 값이 아니다.

### 편집상 선행 컷
직전 컷 ID / 첫 컷이면 start(첫 컷)

### 전환 유형
해당 전환 유형과 서사 시간·장소

### 상태 기준
대상별 CTY 핀·계승 순간 / 계승 기준이 없으면 initial + 초기 상태 근거 핀

### 진입·이탈 상태
대상 / 시작 상태 / 끝 상태
위치·시선·손/소품·자세/동작·신체/감정·의상/환경; 해당 없음은 이유, 필요한 미정은 unresolved

### 유지·변경
유지 대상·상태 / 변경 값 / 사건·생략·단절 근거 또는 unresolved

### 연결 의도
관객이 읽을 동작·시선·반응·대비 또는 도입 의도
