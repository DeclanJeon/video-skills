# QAR-1 — 작성 양식

이 문서는 양식이다. 예시·미정 값은 정본으로 등록하지 않는다.

## 검수 조건

입력 핀 / reviewer_mode / demand / 판정 / 회차

## 레인 A

관찰 근거와 표본 수 / 비교 불가 이유

## 레인 B

hypothesis / 대상별 이탈·공감·댓글·공유

## 레인 C

수요 근거 또는 unknown 및 최소 확인

## 루브릭

R1–R8 점수와 각각의 근거

## 수정·잔여 위험

fix_id / target / owner / severity / evidence / instruction / acceptance
