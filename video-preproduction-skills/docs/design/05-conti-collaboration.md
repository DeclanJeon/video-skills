# 05 — 콘티 회의: 부서 협업 규약

- 문서 ID: `DES-05` · 상태: `draft-r3`
- 위치: P3. 입력은 잠긴 `SCR`, 감독의 연출 노트 `DNT`, P2 바이블 전체. 출력은 `CNT`(컷 표 + 부서 레이어)와 `CTY`(연속성 원장).

## 1. 회의 구조

콘티는 한 사람이 쓰지 않는다. `assistant-director`가 골격을 만들고, 부서가 **의존 순서대로** 자기 레이어를 얹고, 충돌은 감독이 판정한다.

| 라운드 | 부서 | 얹는 레이어 | 이 순서인 이유 |
|---|---|---|---|
| R(-1) | `production-director` | `DNT` 연출 노트: 씬별 목표·서브텍스트·톤/연기 양식·블로킹 콘셉트·카메라 철학 | 모든 부서가 같은 연출 비전에서 출발해야 충돌이 줄고, 충돌 판정의 기준이 생긴다 |
| R0 | `assistant-director` | 씬→컷 분해, 컷 시간표, 대사 배정, CTY 초안([§4 연결 계약](#4-연속성-원장-cty), 축·위치·거리·소품 소유·의상 상태) | 모든 부서가 같은 컷 ID와 시간을 써야 한다 |
| R1 | `performance-director` | DNT 블로킹 콘셉트의 상세 동선, 하위 구간(`.bn`)별 감정 목표·얼굴·호흡·시선·몸·대사 전달·청자 반응 | 무엇을 보여줄지(연기)가 어떻게 찍을지(카메라)를 정한다 |
| R2 | `cinematographer` | 사이즈·앵글·렌즈·심도·구도·무빙·전환, `CAM-nn` | 연기의 가독성을 확보하는 화면 |
| R3 | `lighting-director` | `LGT-nn`, `LOOK-nn`, 컷별 조명 메모 | 카메라 위치가 정해져야 키/역광 방향이 정해진다 |
| R4 | `sound-designer` | 컷별 VOC·AMB·SFX·MUS, 화면 밖 소리 방향, 무음 구간 | 대사 배치·화면 방향이 정해진 뒤 |
| R5 | `vfx-supervisor` | VFX 필요 여부·레이어 | 대부분 N/A, 마지막에 빠르게 |
| R6 | `film-editor` | 컷 포인트·전환·오버랩(J/L컷)·리듬, GEN 경계 제안 | 전체 레이어를 보고 리듬 판단 |
| R7 | `assistant-director` | 충돌 목록 정리 → 감독 판정 요청, 시간표 재검증 | 마감 |

부서는 자기 레이어만 쓴다. 다른 레이어에 문제가 있으면 **고치지 않고** 납품 패킷 `conflicts`에 올린다.

## 2. 충돌 판정

`production-director`는 충돌마다 `RUL-nn`을 남긴다.

```yaml
RUL-03:
  conflict: "C04 ECU 형광등 톱라이트만 유지(lighting) vs 눈 반사광 필요(performance)"
  priority_applied: "이야기 기능 > 부서 취향"
  ruling: "톱라이트 유지, 계산대 흰 장부에서 오는 약한 반사광으로 눈빛 확보(LGT-01b)"
  affected: [CNT#S01-C04.lighting, LGT-01]
```

우선순위: 사용자 제약 > 이야기 기능 > 연속성 > 실행 가능성(선택 모델 한계) > 부서 취향. 판정 후 영향받는 레이어의 부서만 재작업한다.

## 3. CNT 컷 블록 형식

예시는 [EX-02 합성 픽스처](../examples/synthetic-laundromat-34s/fixture.md) 보정판이다.

```markdown
### S01-C02 · 3.0–22.0s · OTS MCU on CHR-02
- beats: PLT.B03;B04;B05 · dialogue: D002–D008 · scene_note: DNT#S01 · gen: (P6에서)
- AD: 연속 19.0s, 화면 내 화자 CHR-02, 전경 CHR-01 어깨(흐림), 계산대 사이 약 1.2m
- performance:
  - .b1 3.0–6.5 반격 (intensity 4): 계산대에 두 손을 짚고 몸을 앞으로; 눈썹 내려 미간에 골(AU4), 아래 눈꺼풀 긴장(AU7), 입술 얇게 다묾 → 말하며 턱 앞으로; 목적: 동정이 아니라 20년의 노동을 인정받으려는 반격; D002 빠르고 또박또박, "버틴 건"에 강세
  - .b2 6.5–10.0 노동의 증거 (intensity 3) …
  - .b4 14.5–18.0 몸의 증거 (intensity 2): 오른손 등을 들어 오빠 쪽으로 내밂(PRP none, 화상 자국이 보이게); 시선은 손이 아니라 오빠 얼굴; D006·D007 느리게, 사이 흡기
- camera (CAM-02): 50mm 상당, 가슴 위, CHR-02 화면 중앙 오른쪽, 전경 CHR-01 어깨·뒤통수 화면 왼쪽 아래 1/5, 거의 고정 + 미세 핸드헬드, .b4부터 감지 불가 수준의 푸시인; 금지: 궤도·크레인·빠른 푸시
- lighting (LGT-01/LOOK-01): 형광등 톱라이트, 가로등 주황 림이 화면 왼쪽 깊은 곳에서 CHR-02 왼뺨(화면 기준 왼쪽)에
- sound: VOC-02; AMB-01 (형광등 웅웅·보일러 쉭); SFX none; MUS none
- vfx: none(realistic drama)
- edit: in hardcut / out hardcut; D008 끝 뒤 1.0s 정지 후 컷
- continuity: CTY.axis-01 (CHR-01 화면 좌/CHR-02 화면 우), CTY.dist-01 (계산대 사이 약 1.2m)
```

## 4. 연속성 원장 (`CTY`)

### 컷 간 연결 계약

R0에서 각 컷을 설계하기 **전에** 편집 순서와 서사적 상태 기준을 정하고, CTY의 해당 컷 항목을 읽어 진입 상태를 작성한다. R1–R6은 이 계약을 소비해 자기 레이어를 구체화하며, R7은 계약과 부서 결과를 대조한다. 계약 정본은 CTY 한 곳이다. CNT·보드 인덱스의 기존 `continuity`에 `CTY@vN#Snn-Cnn`을 기록한다. 작업 중에는 같은 단계의 초안 핀 규칙을 적용하고, 게이트에서는 등록된 실제 버전과 앵커로 교체한다.

CTY 양식의 `## Snn-Cnn`을 실제 컷 ID로 바꾸고 컷마다 아래 여섯 슬롯을 채운다. 번호순이 아니라 확정된 편집 순서를 사용한다.

| 슬롯 | 작성 계약 |
|---|---|
| 편집상 선행 컷 | 상영 순서상 직전 컷 ID. 첫 컷은 `start(첫 컷)`. |
| 전환 유형 | 연속 / 시간 생략 / 장소 전환 / 교차편집 / 회상 / 기타와 설명. 복합 전환은 함께 기록한다. |
| 상태 기준 | 대상별로 계승할 컷·하위 구간의 CTY 핀과 서사 시간·장소를 적는다. 컷 전체 이탈 또는 특정 하위 구간 중 어느 순간인지 명시한다. 기준이 없으면 `initial`과 초기 상태 근거(SCR·DNT·바이블 실제 핀)를 적는다. |
| 진입·이탈 상태 | 대상별 위치·시선, 손/소품 소유·상태, 자세·동작 단계, 신체·감정, 의상·환경의 시작과 끝. 해당 없는 항목은 이유를 적고, 필요한 미정 값은 `unresolved`와 영향 대상을 남긴다. |
| 유지·변경 | 상태 기준에서 유지한 값, 변경 값과 변화 근거(사건 컷·하위 구간 / 경과 시간 / 생략 / 의도적 단절). 변경이 없으면 `유지(대상·상태)`. 공급되지 않은 사건을 임의로 만들어 충돌을 해소하지 않는다. |
| 연결 의도 | 동작 연결 / 시선 / 반응 / 대비 등 관객이 읽어야 할 관계. 첫 컷은 도입 의도. |

**분기 판단**
- 연속 동작: 기준의 이탈 상태에서 현재 진입 상태로 이어지는 동작 단계를 확인한다. 손·소품이 바뀌었는데 사건이나 변화 근거가 없으면 `unresolved`로 남기고 해당 컷 확정을 보류한다.
- 교차편집: 편집상 선행 컷과 상태 기준은 달라도 된다. 다른 장소의 직전 컷 대신 같은 서사의 선행 상태를 참조하며, 보이지 않은 동안의 변화도 근거를 적는다.
- 회상·시간 생략·새 장소: 해당 서사 시간과 공간에 맞는 상태 기준 또는 초기 상태 근거를 고른다. 첫 컷이라는 이유로 모든 대상이 초기화되는 것은 아니다. 의상·나이 등 달라진 상태는 변화 근거를 명시한다.
- 리버스숏: 세계 공간의 위치·소품·동작을 계승하고 새 CAM에서 축·시선·화면 투영을 검토한다. 앞 이미지의 화면 좌우나 구도를 그대로 복사하는 규칙이 아니다.
- 이미지 미생성: CTY·콘티·패널의 텍스트 설계는 진행하고 시각 QA만 미검증으로 남긴다. 관련 선행 패널이 실제로 있고 시각 비교가 필요하면 파일·해시와 확인한 상태를 기록한다. 모델 참조 입력은 해당 상태 유지에 도움이 되고 지원되는 경우에만 선택하며, 이미지를 읽은 것과 모델에 첨부한 것을 구분한다.

**짧은 예 — 교차편집 복귀**
편집 순서 `S01-C01 → S02-C01 → S01-C02`에서 `S01-C02`의 편집상 선행 컷은 `S02-C01`, 인물의 상태 기준은 `CTY@v2#S01-C01`의 이탈 상태일 수 있다. 오른손의 컵이 왼손으로 바뀌었다면 숨은 손바꿈을 추측하지 않고 사건 근거를 요청한다. 이 예의 ID·버전은 양식 예시이며 정본으로 등록하지 않는다.

### 기존 상태 항목

| 항목 | 예 | 기록하는 부서 |
|---|---|---|
| 축·화면 방향 | `axis-01`: CHR-01 화면 좌, CHR-02 화면 우, 시선 정합 | AD (R0), 촬영 확인 |
| 거리·위치 | `dist-01`: 계산대를 사이에 두고 약 1.2m | AD |
| 의상 상태 전이 | `WRD-02a` 전 컷 유지 | AD ← costume |
| 소품 소유 | 두 사람 모두 손에 든 것 없음, 계산대 위 장부(`PRP-01`)는 닫힌 상태 유지 | AD ← production-designer |
| 신체 상태 전이 | CHR-02 목소리·눈: C02.b4 갈라짐·눈시울 붉어짐 → C04 무너짐 | AD ← performance |
| 빛 연속 | LGT-01 전 컷, 시간 경과 없음 | AD ← lighting |

## 5. 경량 회의 모드

러닝타임 ≤60초 **그리고** 씬 ≤3이면 R1–R6을 한 콜시트로 묶어 보낼 수 있다. 이때도 레이어 구분과 부서 서명(`layer_by:`)은 유지해 QA2에서 누가 썼는지 추적한다. 해당 없는 부서는 `none(이유)` 한 줄로 끝낸다.

## 6. 완료 기준

회의 중 작업본은 `CNT@draft`이고 부서는 `CNT@draft#layers.<dept>`를 참조한다. 아래 기준을 모두 만족하면 R7에서 한 번만 `CNT@vN`으로 확정한다([03 §5](03-artifact-index.md#5-변경-전파와-stale)).

- 모든 컷에 R0–R6 레이어가 있거나 `none(이유)`
- 컷 시간표 합 = 러닝타임, 하위 구간이 컷을 빈틈 없이 덮음
- 모든 `D`가 컷·하위 구간에 배정
- `conflicts` 미판정 0
- `CTY`의 모든 상태 전이가 사건(컷·하위 구간) 또는 명시된 시간 생략·단절 근거에 연결
- 모든 컷의 §4 연결 계약에 상태 기준 또는 초기 상태 근거가 있고, 필요한 `unresolved` 및 미판정 변화 근거 0. 누락 시 영향받는 컷·의존 레이어 확정은 보류하되 독립 작업은 계속
