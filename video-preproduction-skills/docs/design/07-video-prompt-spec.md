# 07 — 영상 프롬프트 규격 (프로덕션)

- 문서 ID: `DES-07` · 상태: `draft-r3`
- 소유 스킬: `video-prompt-engineer`
- 입력: `STB` 인덱스, `SHT`/`REF` 이미지, 바이블 전체, `CNT` 레이어, 선택 모델 정보. 출력: `GEN` 묶음 계획, `VPR-nn`, `VPR-nn.map.json`.
- 구조 근거: 사용자 제공 레퍼런스 프롬프트 `REF-PROMPT-01`에서 **구조·패턴만** 가져왔다. 배운 패턴(PP)과 보완 항목(SUP)은 [DES-09](09-reference-prompt-learning.md), 내용을 지운 골격은 [EX-01b](../examples/ref-prompt-01/masked-skeleton.md). 이 문서의 예시는 원작 합성 장면 [EX-02](../examples/synthetic-laundromat-34s/fixture.md)를 쓴다.

## 1. 원칙

1. **프롬프트는 컴파일 결과다.** 새 창작을 하지 않는다. 모든 문장은 인덱스 행이 가리키는 정본에서 온다. 정본에 없는 내용이 필요하면 해당 부서에 `missing_inputs`로 요청한다.
2. **표정은 근육으로, 감정은 목적으로.** 감정 형용사 단독 금지. "분노"가 아니라 "눈썹 내림·미간 골·아래 눈꺼풀 긴장"과 그 감정의 *목적*("동정이 아니라 노동을 인정받으려는 반격")을 함께 쓴다(PP-11, PP-13). FACS AU는 괄호 보조.
3. **시간은 명시적으로.** 모든 대사·표정 변화·카메라 변화는 하위 구간 시간에 묶인다. "점점", "곧" 같은 시간 부사는 구간 안에서만 쓴다.
4. **ID는 사이드카에만.** 프롬프트 본문에 `CHR-01`, `S01-C02` 같은 문자열을 넣지 않는다(화면 글자로 렌더될 수 있고 모델에 의미가 없다).
5. **고정 블록은 문자 단위 동일.** 여러 GEN으로 나눌 때 B1·B3·B4·B6·B7은 GEN마다 같은 문장을 쓴다(정체성·룩 드리프트 방지).

## 2. 영상 프롬프트 템플릿 (8블록)

예시 프롬프트의 구조를 일반화한 순서다. 블록 이름(【…】)은 모델 방언에 맞게 번역하되 순서는 유지한다.

```text
[B1 전역 헤더]
<길이>초, <사실감/장르>, <오디오 방식: 원생 동기 대사 | 무음 | 내레이션>의 <장르> 단편을 생성한다.
화면비 <비율>, <촬영 질감>, <fps 체감>, <그레인>. 이야기는 <시대·지역·장소>에서 벌어진다. <장소 핵심 요소 3–4개>, <빛: 시간대·방향·색온도>.
색은 <팔레트>, <금지 장르감: 현대 물품·광고 느낌 등>.

[B2 연출 의도]
이것은 <피해야 할 연기 양식>이 아니라 <원하는 장면의 본질>이다.
카메라는 <카메라 철학>, 감정은 주로 <연기 수단: 얼굴·호흡·시선·목소리>로 전진한다.

【인물 일관성】                                         ← B3
<인물 A>: <CHR 앵커 문장 원문>. <WRD 상태 문장 원문>. 목소리는 <VOC 서술>.
<인물 B>: …
두 인물은 시종 같은 얼굴·나이·의상·헤어·위치를 유지하며, 얼굴 변화·의상 변화·나이 변화가 없다. 인물은 어떤 실존 배우나 공인도 모방하지 않는다.

<공간·축·블로킹>                                       ← B4
<위치 관계와 거리>. <180도 축: A 화면 좌, B 화면 우>, 시선은 항상 정확히 맞닿는다.

【샷 n | t0—t1초】                                      ← B5 (샷마다 반복)
<렌즈 mm> <사이즈>, <피사체와 방향>. <배경과 심도>. <카메라 움직임 + 금지 움직임>.
t0—ta초:
  <시작 상태>. <관찰 가능한 얼굴 변화 — 부위별, 순서대로>.
  <몸 변화(작게)>. <감정의 목적 한 줄>.
  표정 보조: AUx <이름>, AUy <이름> …
  <화자>가 말한다, <속도·강도·결>:
  "<대사 원문 — 정본과 문자 단위 동일>"
  <강세 단어>에서 <변화>; <쉼 위치>.
ta—tb초: …
<전환: 하드컷 | 디졸브 | 대사 L컷 — 다음 샷으로 이어지는 소리 명시>

【사운드 디자인】                                       ← B6
<대사 언어>로 원생 생성, 화자 엄격 분리, 음절 단위 립싱크.
<화자별 목소리와 감정 궤적>. <호흡·삼킴·울음 등 비언어음 유지>.
환경음은 <AMB 목록>만. <음악·효과음·내레이션 방침>.

【영상 제한】                                           ← B7
<자막/글자/워터마크/로고 금지>. <인물 추가·장면 전환·의상 변화·얼굴 드리프트 금지>.
<장르 금지: 현대 물품·광고 조명 등>. <연기 금지: 과장·지속 비명·슬로모션 등>.
<생성 결함 금지: 이상한 치아·입술 붙음·립싱크 어긋남·시선 이탈·부자연스러운 눈물>.

<핵심 요구: 이 장면이 무엇에 관한 것인지 한 문장, 힘이 어디서 나와야 하는지 한 문장>  ← B8
```

## 3. 타임라인 블록 규칙

1. **구간 연속.** 한 VPR 안의 샷 구간은 0부터 GEN 길이까지 빈틈·겹침 없이 이어진다. 샷 내부 하위 구간도 샷을 빈틈 없이 덮는다. 시간은 소수 1자리.
2. **GEN 로컬 시간.** 프롬프트 시간은 GEN 시작을 0으로 한다. 전체 타임라인 시간은 사이드카에만.
3. **대사 위치 명시.** 모든 대사는 정확히 하나의 하위 구간에 속한다. 대사가 컷을 넘어가면 "이 문장은 끊기지 않고 다음 샷 t초까지 이어진다"를 **양쪽 샷 모두에** 쓴다.
4. **자극 → 반응 순서.** 청자의 반응은 자극 단어가 발화된 구간 **이후**에 둔다. (예시 결함 F2 참조)
5. **화면 밖 화자.** 화면 밖에서 말하면 "목소리는 화면 <방향>에서 들린다"와 화자를 명시하고, 화면 안 인물이 말하지 않는다고 쓴다.
6. **한 구간 한 전환.** 하위 구간 하나에 감정 전환은 최대 1회(시작 상태 → 끝 상태).
7. **말속도 상한.** 구간 길이 대비 대사 길이가 아래를 넘으면 `prompt_lint` 차단. 값은 패키지 기본값이며 프로젝트에서 실측으로 보정한다(`SND#speech-rate`).

| 언어 | 단위 | 보통 | 격앙(상한) | 차단 |
|---|---|---|---|---|
| 영어 | 단어/초 | ≤3.0 | ≤3.8 | >4.0 |
| 한국어 | 음절/초 | ≤7.0 | ≤8.0 | >8.5 |
| 중국어 | 글자/초 | ≤4.5 | ≤5.5 | >6.0 |
| 일본어 | 모라/초 | ≤7.5 | ≤8.5 | >9.0 |

   격앙 상한을 쓰려면 해당 구간 연기 레이어에 "빠르게/격앙"이 있어야 한다. 쉼·호흡·울음 지시가 있으면 그 시간(기본 0.3초/회)을 빼고 계산한다.
   값의 성격: 패키지 기본 운영값이며 연구 근거를 주장하지 않는다. "보통"은 빠른 대화의 상한이고 일상 회화는 이보다 느리다(영어 약 2.5단어/초). 실제 생성 테이크나 TTS로 잰 값이 있으면 `SND#speech-rate`가 이 표를 덮는다.
8. **표정 비트 밀도.** 하위 구간 ≥1.5초 권장. 1초 미만 구간은 정지 표정 유지나 단일 동작만.
9. **좌우 기준 명시.** 모든 좌·우 지시는 `화면 좌/우`(screen-left/right) 또는 `인물의 좌/우`를 밝힌다. 시선 회피·접근은 상대 위치 기준으로 쓴다("그녀에게서 먼 화면 왼쪽 아래로"). (EX-01 F4·F6)
10. **B6 시간 표현.** 사운드 블록의 시점은 샷·대사·단어 기준("샷 1의 마지막 단어에서")으로 쓰고, "마지막 1초"·"초반" 같은 전역 상대 시간을 쓰지 않는다. (EX-01 F5)
11. **샷별 빛 방향 (SUP-10).** 모든 샷의 카메라 단락에 키 라이트 방향을 화면 기준으로 한 줄 쓴다("주황 림이 화면 왼쪽 깊은 곳에서 왼뺨에"). 리버스 샷에서 같은 광원이 반대편에 오는지 `LGT`와 대조한다.
12. **화자 라벨 (SUP-11).** B3에서 정한 인물 라벨("오빠", "동생")을 B5·B6에서 글자 그대로 쓴다. 라벨 사전은 사이드카 `labels`.
13. **소품·손 상태 (SUP-12).** 하위 구간마다 손과 소품 상태를 한 줄 쓴다. 없으면 "손에 든 것 없음".
14. **강도 곡선 (SUP-13, PP-22).** 연기 레이어의 `intensity`(1–5)를 하위 구간마다 둔다. 프롬프트에는 숫자 대신 강도에 맞는 서술로 옮긴다. 같은 샷의 인접 구간 강도가 모두 같으면 경고.

## 4. GEN 묶음 (컷 → 생성 작업)

| 단계 | 규칙 |
|---|---|
| 1. 모델 한계 확인 | 최대 길이·화면비·원생 오디오·참조 이미지 수·언어를 [모델 사실 레지스트리](../../model-facts/_schema.md)에서 확인. 선택 엔드포인트의 값·출처·확인일·유효 상태를 사이드카 `model_facts`에 기록. L10의 계획 경고는 QA4 제출 통과로 간주하지 않는다 |
| 2. 묶기 | 컷 경계를 유지한 채 연속 컷을 최대 길이 안에서 묶는다. 같은 장소·같은 축·대사가 이어지는 컷을 우선 같은 GEN에 |
| 3. 쪼개기 | 한 컷이 최대 길이보다 길면 하위 구간 경계에서만 쪼개고 `C02a/C02b`로 표시, 편집에서 이어 붙인다 |
| 4. 경계 인계 | GEN n의 끝 상태(표정·자세·위치)를 GEN n+1의 시작 상태로 명시. 가능하면 끝 프레임 이미지를 다음 GEN 시작 참조로 |
| 5. 고정 블록 | B1·B3·B4·B6·B7 문장 해시가 모든 GEN에서 같아야 함 |

예시처럼 30초·4컷을 한 GEN으로 처리할 수 있는 모델이면 GEN 1개, 10초 한계 모델이면 컷 경계 기준 3–4개 GEN이 된다. 컷·대사·표정 비트는 어느 경우에도 바뀌지 않는다.

## 5. 모델 방언과 언어

- **내용**(무엇을)은 위 템플릿으로 모델 중립 작성, **직렬화**(어떤 언어·마커·길이)는 선택 모델에서. v1 `creative-production/references/video-prompt-dialects.json`의 직렬화 패턴(narrative / production-spec / edit-command / interactive)을 재사용한다.
- 프롬프트 언어는 선택 모델 문서나 실측으로 정한다. 사용자가 지정하면 그것을 따른다.
- **대사는 발화 언어 원문 그대로** 따옴표 안에 둔다. 프롬프트가 중국어여도 영어 대사는 영어로(예시와 동일).
- 모델별 길이 제한(문자 수)이 있으면 B2·B8부터 압축하고 B3·B5·B7은 압축하지 않는다.

## 6. prompt_lint 규칙

| 규칙 | 검사 | 차단 |
|---|---|---|
| L1 | 샷/하위 구간 시간이 0–GEN 길이를 빈틈·겹침 없이 덮음 | ● |
| L2 | 따옴표 안 대사가 `SCR` 원문과 문자 단위 동일, 누락·추가 없음 | ● |
| L3 | 말속도 상한(§3.7) | ● |
| L4 | 모든 대사에 화자, 화면 안/밖 표시 | ● |
| L5 | B1·B3·B4·B6·B7 해시가 같은 프로젝트의 모든 VPR에서 동일 | ● |
| L6 | 축 서술(좌/우)이 `CTY#axis`와 일치 | ● |
| L7 | B7에 자막/글자/워터마크 금지 포함 | ● |
| L8 | 본문에 내부 ID 패턴(`[A-Z]{2,4}-\d`) 없음 | ● |
| L9 | 반응 지시가 자극 대사 구간보다 앞서지 않음 (사이드카의 `stimulus` 링크로 검사) | ● |

## 8. 재생성

QA5가 테이크 결함을 블록 단위로 지시한다(예: "B5 샷 2 .b4 손을 드는 동작이 과장됨 → 팔꿈치는 계산대에 붙인 채 손등만 든다"). `video-prompt-engineer`는 지목된 블록만 고치고 `VPR` 버전을 올린다. 고정 블록을 고치면 모든 GEN이 stale이 되므로 감독 판정(`RUL`)이 필요하다.

## 9. 오디오 경로 분기

`index-header.json`의 `audio_path`는 `sound-designer`가 P2에서 제안하고 감독이 모델 선택 후 확정한다.

| 경로 | 조건 | 순서 | B6 내용 |
|---|---|---|---|
| `native` | 선택 모델이 원생 대사·립싱크를 지원(근거 `model_facts`) | VPR 하나에 영상·소리 동시 설계 (예시와 같음) | 화자별 목소리·감정 궤적·비언어음·환경음·음악 방침 전부 |
| `separate` | 원생 오디오 미지원·미확인, 또는 사용자가 특정 TTS/음성을 지정 | ① `sound-designer`가 `APR-nn`(대사별 TTS 연기 지시: 속도·강세·쉼·울음, SFX·음악 프롬프트) 작성 → ② 승인 후 감독이 생성 → ③ 실측 길이로 인덱스 시간 보정 → ④ VPR 작성(입 모양은 공급 오디오에 맞춤) | "대사 음성은 공급된 오디오를 쓴다, 새 음성을 만들지 않는다" + 환경음 방침만 (L15) |

`separate`에서는 ③의 실측 길이가 정본이다. 추정 시간표와 다르면 조연출이 시간표를 고치고 인덱스를 갱신한 뒤 VPR을 쓴다.
