# 10 — 컷 간 연결 계약 보완 설계

상태: 승인된 설계 — 2026-11-27 구현 반영. 검증 증거는 `docs/qa/cut-continuity-contract-qa.md`, 최종 완료 상태는 `.ultragoal/goals/active/cut-continuity-contract/goal.md`에서 관리한다.

## 목적과 합의

씬·컷을 나눌 때 연결되는 선행 상태를 먼저 확인하여 이미지와 연출의 불연속을 예방한다. 사용자는 기존 CTY를 강화하고 부서별 소비와 QA를 연결하는 방향의 보완을 요청했다. 아래 세부 필드와 검증 범위는 목표 활성화 승인에 따라 구현한다. 운영 정본은 DES-05 §4이며 이 문서는 변경 설계 기록이다.

기존 CTY는 컷 시작·끝 상태를 기록하고 QA2는 축·시선·의상·소품 연속을 판단하지만, 설계자가 어느 선행 컷의 상태를 계승했는지는 필수 구조가 아니다. 개별 컷이 바이블에 맞아도 컷 사이의 연결 근거가 누락될 수 있다.

## 접근 방식

- **기존 CTY 강화(선택 방향):** 연결 계약의 정본을 CTY에 두고 CNT·패널·프롬프트는 해당 항목을 참조한다. 기존 구조와 QA를 재사용한다.
- 별도 연결 원장: CTY와 상태 정본이 중복되므로 채택하지 않는다.
- 직전 이미지 일괄 참조: 이미지 생성 전 설계를 막고 리버스숏 등에 구도 복제를 유도할 수 있어 채택하지 않는다.

## 계약

각 컷의 CTY 항목에 다음을 작성한다. 아래 이름은 필드 의미이며 구체 직렬화는 기존 템플릿에 맞춘다.

| 필드 | 의미와 완료 조건 |
|---|---|
| 편집상 선행 컷 | 상영 순서에서 바로 앞에 놓인 컷 ID. 첫 컷은 시작점으로 표시한다. |
| 전환 유형 | 연속, 시간 생략, 장소 전환, 교차편집, 회상, 기타 중 해당 유형과 설명. 복합 전환은 실제 관계를 함께 적는다. |
| 상태 기준 | 서사적으로 상태를 이어받는 컷·하위 구간의 CTY 핀. 복수 기준은 대상별로 구분한다. 새 시공간의 최초 등장 등 계승 기준이 없으면 초기 상태의 바이블·SCR·DNT 근거를 적는다. |
| 진입·이탈 상태 | 필요한 대상의 위치, 시선, 손·소품 소유 및 상태, 자세·동작 단계, 신체·감정 상태, 의상과 환경. 무관한 항목은 이유와 함께 해당 없음으로 표시한다. |
| 유지·변경 | 계승할 상태와 달라지는 상태, 변화의 사건·경과 시간·생략·의도적 단절 근거. |
| 연결 의도 | 동작 연결, 시선 연결, 반응, 대비 등 해당 연결에서 관객이 읽어야 할 관계. |

편집상 선행 컷과 상태 기준은 서로 다를 수 있다. 교차편집에서 다른 장소의 직전 컷 상태를 복사하지 않는다. 회상은 서사 시간에 맞는 상태를 사용한다. 의도적인 점프컷과 시간 생략은 상태 동일성이 아니라 변화 근거를 검토한다.

기존 핀 문법을 재사용한다. 새로운 원장이나 필수 CSV 열을 만들지 않고 기존 `continuity` 참조를 통해 계약을 찾는다.

## 적용 순서와 책임

1. **조연출 R0:** 씬·컷 골격을 만들면서 연결 유형과 상태 기준, 진입·이탈 상태 초안을 CTY에 작성한다. 바이블로부터 각 컷을 독립적으로 재초기화하지 않는다.
2. **연기 R1:** 계승할 자세·동작 단계·감정과 반응 원인을 확인하고 담당 상태를 구체화한다.
3. **촬영 R2:** 연결 의도에 맞춰 축·시선·화면 방향과 컷 사이의 구도를 설계한다. 선행 구도를 복제할 의무는 없다.
4. **편집 R6 / 조연출 R7:** 편집 순서와 서사적 상태 계승을 대조한다. 미해결 연결은 감독 판정 대상으로 올리고 정본 확정 전에 해결한다.
5. **스토리보드:** 컷 시작·정점·끝 패널이 CTY의 해당 순간과 일치하도록 설계하고 연결 계약 핀을 유지한다.
6. **이미지 프롬프트:** 계약에서 해당 순간의 관찰 가능한 상태를 추출한다. 실제 선행 패널이 있고 손·소품·위치 등의 시각 비교가 필요하면 관련 이미지를 확인하고 필요한 참조로 사용한다. 이미지가 아직 없어도 텍스트 설계는 진행한다.
7. **QA:** 연결 관계의 완비와 실제 상태·이미지 연결의 타당성을 별도로 판정한다.

## QA와 완료 기준

### 설계 확정 전

- 모든 컷에 전환 유형과 상태 기준 또는 초기 상태 근거가 있다.
- 참조 컷·CTY 핀이 실제 대상에 연결되고 초안·누락·오래된 정본 사용 여부는 기존 원장 규칙으로 검사한다.
- 연속 관계에서는 선행 이탈 상태와 현재 진입 상태가 일치하거나 변화 사건이 설명된다.
- 교차편집·회상·시간 생략은 해당 서사 시간과 장소의 기준을 사용한다.
- 필요한 연결 계약이나 변화 근거가 미해결이면 영향받는 컷의 확정을 보류한다.

### 시트와 프롬프트

- 실제 패널이 있으면 연결되는 이미지들을 함께 비교하여 손·소품·동작·시선·위치와 변화 근거를 확인한다.
- 이미지 미생성은 시각 QA 미검증이며, 텍스트 설계 불가나 전체 독립 작업 중단을 뜻하지 않는다.
- 기계 검사는 구조·참조를 확인하고, 동작·감정·화면 연결의 자연스러움은 근거를 기록한 판단 검사로 남긴다.

## 보완 대상

정본 규약은 `docs/design/05-conti-collaboration.md`에 통합하고 이 문서는 변경 설계 기록으로 남긴다.

- CTY·CNT·부서 레이어 템플릿: 필수 연결 계약 작성 위치와 참조 추가.
- 조연출·연기·촬영·편집·스토리보드·이미지 프롬프트·제작 QA 지침: 담당 단계에서 정본 계약을 읽고 사용하는 절차 추가.
- 아티팩트 계약 QA2·QA3 및 이미지 명세: 관계 검수와 조건부 이미지 참조 기준 추가.
- 테스트·픽스처: 기존 검사 재사용, 필요한 구조 검사를 추가하고 연속/교차편집/회상/시간 생략/초기 컷/이미지 미생성 사례를 포함.
- CHANGELOG: 원인, 변경 경로와 실제 검증 결과 기록.

## 검증 계획과 제한

- 기존 템플릿이 선행 관계와 상태 변화 이유를 누락해도 통과하는 사례를 먼저 재현한다.
- 문서 단어 존재 검사만으로 자연스러운 연출을 검증했다고 주장하지 않는다. 구조 회귀 검사와 사례별 판단을 분리한다.
- 검증 사례: 컵을 든 손의 무근거 변경, 동작 연결, 리버스숏, 교차편집 후 복귀, 회상, 시간 생략, 첫 컷, 이미지 없는 텍스트 설계.
- 기존 테스트와 문서 정합성 검사를 실행하고 변경 전부터 있던 실패와 새 실패를 구분한다.
- 행동 검증에 별도 에이전트가 필요하면 실행 권한을 확인한다. 독립 검증을 수행하지 않았으면 명시한다.
- 공급자 호출, 이미지 생성·과금, 설치본 동기화, 커밋·푸시는 이 변경의 실행 범위가 아니다. 기존 미커밋 수정은 보존한다.
