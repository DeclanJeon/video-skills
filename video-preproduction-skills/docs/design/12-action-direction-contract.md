# 12 — 액션 연출 계약 (레퍼런스 역설계 → 콘티·프리비즈·프롬프트)

- 문서 ID: `DES-12` · 상태: `draft-r1` · 작성: 2026-11-27
- 적용: 추격·전투·괴수·재난·스턴트처럼 **물리적 위협과 동작이 이야기를 운반하는 구간**. 대화극·정적 드라마에는 강제하지 않는다.
- 근거: 사용자 제공 레퍼런스 8편의 실제 프레임 검토(항만 드래곤, 숲 수호자, 무협, 신사 원테이크, 액션로맨스, 컨테이너 골목, 사무라이, 좀비 45초). 관측 원본은 해당 프로젝트 `00_brief/REF-ANALYSIS-*.md`에 둔다. 아래 수치는 **패키지 기본 운영값**이며 성과 근거가 아니다.
- 소유: 감독(채택), 조연출(액션 샷 표), 촬영(샷 팔레트), 스토리보드(프리비즈·패널), 영상 프롬프트(블록 형식), 제작 QA(QA2/QA3).

## 1. 관측된 실패 (이 계약이 막는 것)
텍스트 콘티가 다음 상태로 통과됐다: 액션 구간 평균 컷 4.6초, 위협이 보이는 컷 7/24, 카메라 "고정" 다수, 손·발·눈 인서트 0, 인물이 카메라를 보고 일렬로 서는 타블로 반복, 공격이 "빛의 파동" 같은 추상어로만 기술, 공간 지도 없이 위협 위치가 컷마다 바뀜. 인덱스·타임라인 검사는 모두 PASS였다 — 구조 검사는 박진감을 보지 않는다.

## 2. 레퍼런스 확인 규칙
사용자가 영상/링크를 주면 **실제 프레임을 열어** 분해한다(최소 1fps 시트, 핵심 구간 더 촘촘히). 프롬프트 글만 받았으면 "영상 미확인"으로 명시하고 글이 요구하는 촬영 문법(예: 발 로우앵글, 저공 스윕, 규모 와이드)을 체크리스트로 콘티에 옮긴다. 장소·색만 가져오고 촬영 문법을 버리는 것을 금지한다.

## 3. 구조 규칙
1. **2템포.** `action` 구간과 `release`(감정·여운·대사) 구간을 나눈다. 감정 대사는 액션이 끝난 뒤에 둔다.
2. **콜-리스폰스 라운드.** 한 라운드 = 위협의 공격 → 특정 인물의 물리적 위기(같은 프레임에 위험원) → 동료/주인공의 **고유 반격 아이디어** → 환경 반응. 라운드마다 위협 수위나 반격 규모가 커진다.
3. **고유 기술.** 주요 인물마다 반복 가능한 시그니처 동작 1개. 클라이맥스는 이것들의 결합으로 만든다. 적이 여럿이면 적마다 다른 기술·다른 착지 위치.
4. **인과 체인.** 모든 공격/반격 컷은 `예비동작>발사/돌진>접촉>반응>흔적`을 기록한다. 흔적(그을음·물보라·찌그러짐·쓰러진 위치)은 다음 컷부터 유지한다.
5. **위치 유지.** 쓰러진 사람·부서진 소품·흔적은 다른 컷으로 갔다 와도 같은 위치에 있다(사라짐·순간이동 금지).

## 4. 샷 팔레트 (action 구간 기본값, `action_lint.py`가 검사)
| 코드 | 규칙 | 기본값 |
|---|---|---|
| AL01 | 평균 컷 길이 | ≤ 2.5초 |
| AL02 | 매크로/ECU 인서트(눈·손·발·도구·접촉점) | ≥ 20% |
| AL03 | 로우/탑다운/POV 앵글 | ≥ 20% |
| AL04 | 위협(그림자·신체 일부·전신)이 같은 프레임 | ≥ 60% |
| AL05 | 움직이는 카메라(트래킹·핸드헬드·휩팬·푸시 등) | ≥ 40% |
| AL06 | 정면 일렬 타블로 | 0 (release 구간 기념컷만 예외) |
| AL07 | 모든 컷에 공간 존·화면 방향 | 필수 |
| AL08 | 공격/반격의 인과 체인 4단 이상 | 필수 |
| AL09 | 연속 두 액션 컷의 크기·앵글·무빙 동일 | 금지 |
| AL10 | 컷 시간 연속 | 필수 |

덧붙여(판단 검사): 거대 위협이 있으면 규모 와이드/탑다운 ≥2, 위협 신체 일부를 전경에 둔 깊이 샷 ≥15%, 매크로↔와이드 교차. 값을 바꾸려면 감독 RUL에 이유를 쓴다.

## 5. 액션 샷 표
조연출은 CNT와 함께 [`action-shots-template.csv`](../../assistant-director/assets/action-shots-template.csv) 열을 채운다: `cut,t_start,t_end,segment,zone,screen_dir,shot_size,angle,camera_move,threat_in_frame,beat_role,cause_chain,lineup`. 인덱스 CSV 열은 바꾸지 않는다. `python3 scripts/action_lint.py --shots <csv>`로 QA2 전에 검사한다. 종료 0은 박진감 판정이 아니라 최소 문법 충족이다.

## 6. 공간 지도와 프리비즈
1. 장소를 3–5개 **존**(엄폐, 도주로, 개방 공간, 랜드마크/고지)과 위협 이동 경로로 고정한다. 모든 컷은 존·화면 방향·위협 위치를 가진다.
2. 인물 ≥3명 + 대형 위협, 또는 구조·인계·가림이 의미를 바꾸면 **패널 이미지 전에** [공간 프리비즈](../../storyboard-artist/references/spatial-previs.md)를 실행한다(프록시 박스·인물 캡슐·위협 프록시·컷별 카메라 실제 렌더·path-map).
3. 프리비즈 스틸을 패널 생성의 **구도 참조**로 함께 보낸다(얼굴·의상 참조와 역할 분리). 프리비즈는 배치·가림·구도 증거이지 손 접촉·해부학·최종 연기 증거가 아니다.

## 7. 영상 프롬프트 블록 형식 (액션)
성공 사례의 공통 골격을 쓴다: 사양 1줄 → `@image` 역할 매핑 → 인물/의상 잠금 → 장소 1단락(존 포함) → **타임라인 블록(모델 지원 단위, 보통 2–3초): 카메라 1개 + 사건 동사 1–2개 + 결과 상태** → 오디오 1단락 → 불변 규칙(인원수·위치 유지·소품 소유·비노골) → 짧은 금지. 감정 설명·연출 의도는 블록 밖 DNT에 남긴다. 기존 8블록 명세와 사이드카 추적은 그대로 유지하며, 액션 구간의 B5만 이 형식으로 압축한다.

## 8. 변신·봉인 세트피스 (레퍼런스 장면 모방 규칙)
사용자가 변신/봉인 같은 **정형 장면**을 레퍼런스 영상으로 주면 다음을 따른다.
1. 영상 전체를 실제 프레임으로 열어 컷 표(시간·샷·동작·기능)를 만들고, 장면(Scene)과 컷(Cut)을 구분해 기록한다. 컷 시각은 검출 후보와 직접 확인을 구분한다.
2. **구조·샷 문법·리듬·동작 논리**를 이전한다. 고유 소품·상징물을 그대로 쓸지 교체할지는 사용자에게 확인하고 결정을 교체표에 기록한다(사용자가 그대로 쓰라고 하면 그대로 쓴다). 신체 노출 연출은 어느 경우에도 가져오지 않고 옷을 입은 채 빛으로 대체한다.
3. 변신 구조: 아이템 영웅샷 → 몸으로 흡수 → 월드 변환(빛기둥·환경 반응) → 의상 단계 생성 → 부위별 클로즈업 감김 → 눈 뜸 → 방사형 배경 포즈. 15초 각색은 평균 컷 길이 ≤2.2초(원본 실측: 변신 T1 1.65초, 봉인 S1-B 2.09초. 15초로 압축 각색하면 ≤1.6초 권장, 원본 길이 복제는 원본 ASL을 기준으로), 클로즈업 ≥30%·와이드 ≥15%·움직이는 카메라 ≥60%.
4. 봉인 구조: 결박 → 선언(결정 제스처 클로즈업) → 압축(흰 섬광·세계 전환 후 적이 작은 상징물로 응축). 적은 죽지 않고 상징물이 된다. 봉인 뒤 주인공 얼굴로 돌아와 호흡을 둔다.
5. 샷 표의 `segment`는 `setpiece`로 표기해 위협 노출(AL04)·인과 체인 요구를 면제하고 AL11–AL13(자체 속도·카메라·클로즈업/와이드 비율)을 적용한다. 봉인의 결박·접촉 컷은 `action`으로 둔다.

## 9. 복제 금지
레퍼런스의 인물·의상 문구·고유 개그·로고·대사·음악은 옮기지 않는다. 옮기는 것은 메커니즘(콜-리스폰스, 인서트 운반, 깊이 레이어, 2템포, 위치 유지, 연속 테이크)이다.
