# 구현 실행 큐

> 사용자 결정으로 현재 설계 작업을 종료·동결한다. [설계 마감 기록](DESIGN-CLOSEOUT.md) 참조. 아래 실행 항목은 재개용 보존 상태이며, 자동 소진하거나 완료로 변경하지 않는다. 미릴리스·설치 금지 유지.

정본 순서: [작업지시서](WO-00-index.md). 남은 작업의 완료 기준과 실행 상태는 [WO-15 마감 지시서](WO-15-closeout.md)에 기록한다. 로컬 구현, 에이전트 행동, 실제 미디어 검증을 별도로 닫는다.

| 항목 | 상태 | 남은 작업 |
|---|---|---|
| WO-03 | 로컬 검증: 등록된 단어 구간의 끝과 반응 시작 대조 | 실제 단어 타이밍·모델 근거 및 자유 서술 판단 |

| WO-06 | 지침·양식·[평가 입력](../../evals/qa1/fixtures/compact-cases.md) 작성 | 실제 반복 행동 검증; 기대값은 입력과 분리 |
