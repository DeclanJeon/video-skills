# WO-13 — 종단 평가 (v1 대비)

**Goal:** 같은 브리프로 v1과 v2를 끝까지(텍스트 단계 + QA4까지) 실행해 v2가 요구사항(REQ-01–12)을 충족하고 v1보다 나은지 판정한다.
**Spec:** DES-00 §2 REQ 표 · **의존:** WO-06, WO-11, WO-12

## 시나리오
| ID | 브리프 | 확인 초점 |
|---|---|---|
| X-1 | "새벽 3시 편의점, 야간 알바생과 점주가 계산대 CCTV 영상을 두고 맞서는 40초 사실주의 2인극, 한국어 원생 대사" — 레퍼런스·EX-02와 다른 원작 전제(평가 과적합 방지) | QA1 작동, 디자인 부서 전부, 콘티 회의, 말속도 사전 검출, 8블록 VPR, PP 커버리지 |
| X-2 | "직장인 공감 60초 쇼츠, 한국어 대사, 9:16" | 한국어 말속도, 벤치마크 차용 원장, 경량 모드 |
| X-3 | "대사 없는 20초 감성 애니메이션 광고" | 무성 모드, VOC/D 없음 처리(`none(이유)`), VFX 레인 |

실행에는 변경하지 않은 동일 브리프 파일을 사용한다: [X-1](../../evals/e2e/X-1.md), [X-2](../../evals/e2e/X-2.md), [X-3](../../evals/e2e/X-3.md). 채점표는 실행 세션의 입력에 섞지 않는다.

## 채점표 (항목당 0/1, 근거 파일 경로 필수)
1. QA1이 각본 잠금 전에 실행되고 판정·수정 지시가 SCR ID를 가리킨다 (REQ-02)
2. BOR에 차용/변주/고유 처리가 있고 표현 차용 0 (REQ-03)
3. 각본의 모든 대상이 바이블 ID를 가진다 — CK-B 0 error (REQ-04)
4. CNT에 부서 레이어 R0–R6가 모두 있고 `layer_by` 추적 가능 (REQ-05/06)
5. QA2가 실행되고 `index_lint`·`timeline_check` 결과가 첨부 (REQ-07)
6. IMG 프롬프트가 REF 우선·앵커 원문, `prompt_lint --kind image` 0 (REQ-08)
7. STB 인덱스 행의 필수 열 빈칸 0, 모든 참조 해결 (REQ-10)
8. VPR이 컷·하위 구간 타임라인을 가지며 `prompt_lint` 0 (REQ-09/11)
9. VPR에 EX-01 §1 강점 항목 전부 존재 (REQ-12)
10. 감독의 직접 창작물은 `DNT`뿐이고 나머지는 크루 절차로 작성(인라인이면 `acting_as`) (REQ-01)
11. 응답 마감 줄 형식 준수
12. 숫자 성과 예측 없음
13. VPR이 PP-01–25를 적용 또는 사유 있는 N/A로 처리하고, 산출물 전체에서 `REF_LEAK` 0 (REQ-12, DES-09)

## Steps
- [ ] **1. v1 기준선** — X-1–X-3을 v1 `creative-production`으로 실행, `qa/wo-13/v1/`
- [ ] **2. v2 실행** — 깨끗한 세션, `qa/wo-13/v2/`
- [ ] **3. 채점** — 채점자는 실행자와 다른 세션(가능하면 서브에이전트, 불가하면 그 사실 기록)
- [ ] **4. 판정** — v2 ≥ 12/13 (시나리오별) 이고 v1보다 높으면 WO-14 진행. 미달 항목은 해당 WO로 되돌림
- [ ] **5. 비용 기록** — 같은 브리프·모델·추론 설정으로 v1/v2의 입력·출력 토큰과 총 경과 시간을 기록. 콘티 구간은 별도 집계. 위임이 허용된 경우에만 인라인/서브에이전트 비교. 3인 [EX-03](../examples/synthetic-meeting-3p-45s/fixture.md)과 무대사 [EX-04](../examples/synthetic-silent-20s/fixture.md)는 패턴 적용/N/A 근거와 누출 검사 결과를 별도로 기록
