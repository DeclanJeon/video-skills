## 큐 소진 규칙

의존성이 열린 첫 항목을 실행하고 증거 경로를 적는다. 실패하면 원인을 수정하고 해당 단계부터 재검한다. 외부 승인·독립 검수·실제 결과가 없으면 `BLOCKED`와 해제 조건을 기록한 뒤 다른 실행 가능 항목을 진행한다. 모두 완료 증거가 있을 때만 100%다. 초안·시뮬레이션·로컬 통과로 실제 제출·실행을 대체하지 않는다. v1은 변경하지 않는다. 비용 한도는 요청자가 정한 경우에만 사용한다. 외부 업로드, 유료 제출, 설치·전환은 각각 승인 범위 안에서만 한다.

**진행률 보고:** 작업이 끝날 때마다 해당 트랙의 검수 통과 수 / 전체 수와 백분율(반올림)을 기록한다. X-3는 X1–X6, v2 릴리스는 R1–R6, 개별 행동 세트는 해당 WO 사례 수가 분모다. 하위 사례 통과와 상위 이정표 완료를 중복 합산하지 않는다. 착수·실패·차단으로 완료율을 올리지 않는다.
