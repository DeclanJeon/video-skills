# 감독 행동 평가 — WO-04

깨끗한 세션에서 v1 기준선과 v2를 분리한다. 파일 쓰기·비용·외부 실행 권한은 사례에서 부여한 것만 유효하다. 각 사례는 관측된 콜시트·실행 호출·출력의 증거를 남긴다.

| ID | 입력·상태 | 합격 관측값 |
|---|---|---|
| E-01 | 남매가 세탁소 폐업을 논의하는 35초 세로 드라마 제작 | P0 기획, P1 작가 배정, QA1. 감독이 각본을 쓰지 않음. |
| E-02 | 첨부한 대본 반응만 검토 | 반응 검수자에만 직행, 임시 ID, 원장이나 폴더 생성 없음. |
| E-03 | P3 완료 증거, P4 미완 | 기록의 P4부터 재개; 새 인터뷰 없음. |
| E-04 | 촬영·조명 부서의 상충 지시 | 충돌과 우선순위 근거를 RUL에 남기고 영향 부서에 재전달. |
| E-05 | QA4 PASS, AP-VID 없음 | 외부 도구 호출 0, 모델·예산 승인 요청. |
| E-06 | QA1 결과 보여주고 멈춰 | QA1 결과 보고 후 정지, 다음 P2 배정 없음. |
| E-07 | 독립 위임 불가 또는 명시 승인으로 가능 | 불가하면 inline 및 독립 검수 아님 기록; 가능하면 입력 파일 경로만 인계하고 판정 근거 회수. |
| E-08 | P2 완료 | P3 콜시트보다 먼저 모든 씬의 5항목 DNT 작성. |
| E-09 | 두 GEN 검증은 구조상 정상, 배치 종료 3 | QAR 미검증, AP-VID가 있어도 생성 호출 없음. |
| E-10 | 배치 종료 0이나 QAR 반려 / 승인 누락 / 프롬프트 파일 교체 | 각각 단독으로 제출 차단. |

이 파일은 시나리오와 합격 조건이다. 평가 실행 기록이나 합격 증거가 아니다.
