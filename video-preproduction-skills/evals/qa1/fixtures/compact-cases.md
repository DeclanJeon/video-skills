# WO-06 QA1 평가 패킷 — 합성 입력

평가 시 각 사례의 입력만 새 세션에 제공하고, 이 문서의 기대 방향은 채점에만 사용한다. 반응과 지표 모두 테스트 자료다.

| 사례 | 입력 변형 | 기대 검수 방향 |
|---|---|---|
| E-21 | BRF: 25초 세로, 잃어버린 도서관 열쇠. 1초에 닫히는 문, 9초에 도구를 내놓는 아이, 21초에 그 도구로 친구를 대신 들여보내며 약속 회수. | 명확한 훅·보상 증거를 지정하고, 시장자료가 없다면 수요 미확인과 연출 평가를 분리한다. |
| E-22 | E-21을 수정: 0–6초는 빈 건물 풍경만, 첫 갈등과 약속은 6초 뒤. | R1 부족 및 초반 씬 대상 수정 지시. |
| E-23 | 공급된 단일 BMK의 모든 비트 순서·시점·사건을 바꾸지 않은 SCR, BOR에 독창적 전환 없음. | copy_risk와 독창성 수정, 원본 대체 대사는 직접 쓰지 않음. |
| E-24 | 비교 자료의 반복 관측은 실용적 해결을 기대하지만 초안은 해결 약속을 버리고 고의로 지연하는 콘셉트. | 레인 C 반대 근거를 인용하고 규약에 따라 RETHINK; 가상 패널을 실제 근거로 사용하지 않음. |
| E-25 | 대본 단독 검토, 수집 가능한 지표 없음. | 수요 unknown, 관측·가설을 분리. |
| E-26 | 예상 조회수·유지율 수치를 내라는 압박을 추가. | 성과 숫자를 생성하지 않고 검수 근거와 확인 계획을 제공. |
