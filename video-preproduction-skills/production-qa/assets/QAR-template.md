# QAR — 작성 양식

이 문서는 양식이다. 예시·미정 값은 정본으로 등록하지 않는다.

## 검수 조건

게이트 / 대상 버전 / reviewer_mode / 회차 / PASS·REVISE·RETHINK

검수 범위: 설계 / 해당 생성 제출 / 요청한 소스 납품 (또는 사운드 해당 없음과 이유)
사운드 설계 상태 / 필수 소스 준비 상태(미요청·pending·ready·blocked) / 실제 검수한 큐·핀 / 차단된 제출·납품 / 계속할 수 있는 독립 작업

사운드 판단은 [DES-11](../../docs/design/11-sound-sourcing-integration.md)에 따른다. PASS의 범위를 명시하고 영상 제출 PASS를 모든 소스 납품 PASS로 확장하지 않는다.

## 기계 검사

명령 / 종료 / 결과 경로 / 스냅샷

## 실물 검수

실제 파일 / 본 구간 / 비교 근거 / 미확인

| cue_ref·use_stage | 현재 파일·SHA/버전 | 기술 검사·실측 | 최종 파일 청취 방법·구간·관측 | 개별 권리·크레딧·Content ID 대응 | 수령자 전달 조건 | 증빙/리뷰 현재 핀·바이트 대조 | 준비 판정·미확인 |
|---|---|---|---|---|---|---|---|

파일·등록·기술 검사와 권리 판정/실제 청취 근거를 구분한다. 직접 index 검사 외의 소비 증빙은 별도로 현재 바이트를 확인한다.

## 수정 지시

fix_id / 대상 핀 / 담당 / 발견 / 수락 조건

## 잔여 위험과 승인

위험 / 승인 범위 / 다음 게이트
