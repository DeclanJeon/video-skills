## 실제 응답

### 감독 콜시트 초안 — 남매의 세탁소 폐업 논의

**작업 순서:** P0 감독 → 벤치마크 담당 → P1 각본가 → QA1 관객반응 검수 → 감독이 첫 판정 확인 후 정지.

**공통 고정 조건:** 남매가 세탁소 폐업을 논의하는 **35초 한국어 세로 드라마**. 구체 플랫폼·대상 관객·톤은 P0에서 확정하고, 추론한 내용은 브리프에 표시합니다. 아래 `tmp:` 표기는 인계 예정 항목을 가리키는 임시 표기입니다. 프로젝트와 정본 버전 핀은 아직 없습니다. 전 콜시트의 실행 권한은 `authority: []`이며, 지금은 자료 검색, 프로젝트·원장 저장, 각본 작성, 이미지·영상 생성, 외부 제출을 하지 않습니다.

| 순서 · 담당 | 입력 → 배정 작업 | 인계물 · 정지점 |
|---|---|---|
| **1. P0 · 감독** (`production-director`), `tmp:CALL-P0-01` | 사용자 요청 → 제작 목적·대상·플랫폼·길이·톤을 정리하고, 확정 요구와 추론을 구분합니다. | `tmp:BRF` 브리프 예정. 벤치마크 담당에게 넘기는 데서 정지. |
| **2. P0 · 벤치마크** (`concept-benchmark`), `tmp:CALL-P0-02` | `tmp:BRF` → 원칙은 비교 가능한 사례 3건 이상의 구조를 분석하고 차용 근거를 남기는 것입니다. 검색 금지가 유지되고 제공 자료도 없다면 벤치마크는 `unknown`(자료 미제공·검색 제외), 차용 근거는 없음으로 인계합니다. 사례나 수치를 꾸며 넣지 않습니다. | `tmp:BMK` 벤치마크, `tmp:BOR` 차용 원장 예정. 분석 또는 미확인 사유를 인계하는 데서 정지. |
| **3. P1 · 각본가** (`story-writer`), `tmp:CALL-P1-01` | `tmp:BRF`·`tmp:BMK`·`tmp:BOR` → 시놉시스 → 플롯/비트 → 한국어 각본 초안 순으로 개발합니다. 모든 비트를 씬에 배정하고 대사에 `Dnnn` 식별자를 붙입니다. | `tmp:SYN`·`tmp:PLT`·`tmp:SCR` 초안 예정. 러닝타임 추정치가 **31.5–38.5초**(35초 ±10%)를 벗어나면 납품 `assumptions`에 사유와 보정안을 적고, 초안 인계에서 정지. |
| **4. QA1 · 관객반응 검수** (`audience-reaction-qa`), `tmp:CALL-QA1-01` | 감독이 먼저 초안의 비트 배정·대사 식별자·시간 추정과 예외 기록을 확인해 증거를 넘깁니다. 검수 담당은 `tmp:SCR` 초안·`tmp:BMK`·`tmp:BOR`로 초반 훅, 폐업 갈등의 명료성, 감정 전환과 결말, 35초 적합성을 첫 회차에서 전수 검토합니다. 벤치마크 미확인과 예상 관객 반응(가설)을 실제 관측과 구분합니다. | `tmp:QAR-1`에 `PASS` / `REVISE` / `RETHINK` 중 첫 판정과 근거, 필요시 수정 대상·담당·완료 조건을 남깁니다. 감독은 첫 판정만 확인·보고하고 정지. |

실행 시에는 해당 단계의 현재 입력을 확인한 뒤 콜시트를 발행하고, 부서별 `DLV`로 산출물·가정·점검 결과·누락 입력을 받습니다. 납품 자체는 QA 통과가 아닙니다. 첫 판정 이후의 일반 경로는 `PASS`면 각본 잠금, `REVISE`면 P1 수정, `RETHINK`면 P0 재검토지만, 이 콜시트는 어느 경우에도 그 경로를 시작하지 않습니다. 지금 제공한 것은 배정 초안뿐이며, 각본이나 QA 판정은 아직 없습니다.

대기: 사용자 지정 정지 — 필요: P0–QA1 실행 요청

3. `functions.read` — 감독 스킬에서 연결된 `docs/design/01-pipeline-and-gates.md` 열람.
