## tmp:CHR-01 — 오빠

### anchor

60대 초반의 마른 남성으로, 짧은 반백 머리에 안경을 쓰고 눈가에 주름이 있다.

### persona

- **욕망:** 보증금이 더 오르기 전에 폐업과 매각을 결정해 더는 감당 못 할 부담을 막고 싶다.
- **회피:** 누가 이 가게를 매일 지켜 왔는지 따지는 대화를 피한다. 동생의 노동을 어떻게 생각하는지 각본은 확정하지 않는다.
- **결정 규칙:** 비용이 감당할 수 있는 선을 넘는다고 판단하면, 더 버틸 방법보다 그만둘 시점부터 말한다. `D001`에서 보증금 인상 소식을 먼저 꺼낸다.

### voice-identity

중저음, 살짝 마른 질감. 생활 구어로 숫자와 기한에 힘을 주고 문장 끝은 낮게 닫는다. `D001`의 “다음 달부터”는 분명하게, “못 버틴다니까”는 소리를 키우지 않고 단호하게. 특정 사투리나 실제 성우를 지정하지 않는다.

### expression-habits

숫자나 기한을 말할 때 턱을 조금 내리고 상대를 본다. 자신이 가게를 지켜 오지 않았다는 지적을 받으면 시선이 잠깐 계산대로 떨어지고 입술이 다물린다. 침묵을 새 대사로 메우지 않는다.

### 7뷰

| 보기 | 가시 기준 |
|---|---|
| 1. 정면 | 안경 너머 눈가 주름, 이마 위 짧은 반백 머리. 어깨 폭에서 마른 체형이 읽힌다. |
| 2. 왼쪽 ¾ | 가까운 눈가 주름과 안경테, 짧은 옆머리. |
| 3. 오른쪽 ¾ | 반대쪽 눈가와 안경테. 머리 길이와 체형은 그대로다. |
| 4. 왼쪽 측면 | 관자놀이를 지나는 안경 다리, 짧은 옆머리와 마른 목선. |
| 5. 오른쪽 측면 | 반대쪽 안경 다리와 옆머리, 같은 목선. |
| 6. 후면 | 짧은 반백 머리의 뒤통수와 좁은 어깨선. 얼굴 표지는 이 각도에서 확인하지 않는다. |
| 7. 표정 3종 | **평상시:** 턱과 입술에 힘을 빼고 바라본다. **통보:** 턱이 조금 내려가고 문장 끝에서 입술이 닫힌다. **응답을 피할 때:** 눈이 계산대로 내려가고 입술이 다물린다. |

**불변:** 60대 초반, 마른 체형, 짧은 반백 머리, 안경, 눈가 주름. 표정이 바뀌어도 안경을 벗기거나 눈가 주름을 지우지 않는다.

## tmp:CHR-02 — 동생

### anchor

50대 중반의 다부진 여성으로, 단발머리를 묶고 있으며 오른손 등에 다리미 자국이 있다.

### persona

- **욕망:** 이십 년간 가게를 지킨 사람이 자신임을 오빠가 인정하고, 가게를 파는 일이 자기에게 무엇을 빼앗는지 알아주길 바란다.
- **회피:** 일터를 잃는 일을 매각 대금만으로 정산하거나, 동네에서 자신을 불러 주던 이름이 사라지는 일을 대수롭지 않게 넘기지 못한다.
- **결정 규칙:** 오빠가 버티기 어렵다는 결론부터 내리면, 먼저 셔터를 여닫은 시간과 장부를 봤던 횟수, 손의 자국으로 누가 버텼는지 따진다(`D002–D007`). 돈 얘기로는 설명이 되지 않을 때, 간판이 내려가면 자신에게 무엇이 남는지 묻는다(`D008–D011`).

### voice-identity

중음에서 중저음, 또렷한 자음에 약간 거친 숨이 섞인다. “이십 년을”은 숫자를 똑똑히 떼어 말한다. 화면 밖 `D009–D010`에서도 같은 음색을 유지하고, `D010`의 끊김 뒤 `D011`은 음량을 낮춘다. 화면 밖이라고 내레이션 음색으로 바꾸지 않는다.

### expression-habits

오빠의 말을 되받을 때 눈을 맞추고 턱을 조금 앞으로 내민다. `D006–D007`에서는 상대가 볼 수 있게 오른손 등이 드러나도록 손을 들어 잠깐 멈춘다. 말을 잇기 어려워지면 입술을 한 번 다문다. `D009–D010`은 화면 밖이므로 그 구간에 얼굴 반응을 지정하지 않는다.

### 7뷰

| 보기 | 가시 기준 |
|---|---|
| 1. 정면 | 머리카락이 뒤로 모인 윤곽과 다부진 체형. 오른손 등이 보이면 다리미 자국을 유지한다. |
| 2. 왼쪽 ¾ | 볼 옆에서 뒤로 모이는 단발 윤곽. 오른손이 가려져도 왼손에 자국을 추가하지 않는다. |
| 3. 오른쪽 ¾ | 가까운 쪽 머리선과 묶은 단발 윤곽. 오른손 등이 보일 때 다리미 자국을 확인한다. |
| 4. 왼쪽 측면 | 뒤로 모인 옆머리, 단발 끝과 목선의 관계. 왼손 등에는 해당 자국이 없다. |
| 5. 오른쪽 측면 | 같은 단발 길이와 다부진 몸선. 오른손 등을 돌려 보일 때만 자국이 드러난다. |
| 6. 후면 | 뒤통수에서 모인 짧은 머리와 다부진 어깨선. 손이 가려지면 자국도 보이지 않는다. |
| 7. 표정 3종 | **평상시:** 턱과 입술에 힘을 빼고 바라본다. **반문:** 눈을 맞춘 채 턱이 조금 앞으로 나온다. **말 잇기 직전:** 닫혔던 입술이 한 번 열린다. 눈물을 필수로 두지 않는다. |

**불변:** 50대 중반, 다부진 체형, 묶은 단발, 오른손 등의 다리미 자국. 시점이 바뀌어도 흉터 방향을 반전시키거나 헤어 길이를 바꾸지 않는다.

### 연속성과 부서 경계

두 인물 모두 1–6은 방향, 7은 세 표정을 담는 묶음이다. 좌우 뷰는 인물의 해부학적 좌우이며 계산대 배치나 화면 좌우와 별개다. 의상은 각본의 무전환 조건만 유지하고 추가 설계는 의상 부서에 남긴다. 형광등과 가로등으로 색이 다르게 보여도 머리색, 나이, 체형, 식별 표지가 달라지지 않는다. 음성은 인물 정체성만 제안하며 실제 캐스팅은 음향 부서 범위다.
