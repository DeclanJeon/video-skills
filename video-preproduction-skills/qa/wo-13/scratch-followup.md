# WO-13 후속 평가 — 복구 결과

원 실행은 확장 재시작으로 중단됐다. 복구 워크플로 `2f1a7c4f-16d0-4fac-8f40-a4fe65d6303d`가 기존 6개 작업 결과를 재사용하고 독립 리뷰를 완료했다. 새 비교 세션을 중복 실행하지 않았다. [원본 비교·검수·로그 묶음](scratch-followup.tar.gz)과 [해시](scratch-followup.sha256)를 보존했다. 압축 파일은 작업 증거이며 설치나 테스트 입력이 아니다.

| 사례 | v1 | v2 |
|---|---:|---:|
| X-1 | 1/13 | 7/13 |
| X-2 | 1/13 | 7/13 |
| X-3 | 1/13 | 8/13 |

별도 검수자가 매긴 증거 점수다. v2는 3건 모두 로컬에서 정본을 재열람해 QA1·QA2에 통과했고, 실제 패널·시트 증거가 없어 QA3에서 멈췄다. v1도 실물 준비 게이트에서 멈췄다. 정식 QA4와 12/13 기준은 미충족이다.

브리프 해시·모델·추론 설정은 보고서에서 쌍별로 일치했다. 토큰과 전체 경과 시간은 원본 리뷰에 보존되어 있지만, 콘티 단계만의 동일 범위 시간과 QA4까지의 동일 종료점이 없어 비용 우위를 판정할 수 없다. 정식 `runs.json`은 채우지 않는다.

재현된 세 결함을 로컬에서 수정: 단독 씬 ID 누출, 증거가 있는 빈 프레임의 정체성 비적용, 등록된 문서와 프롬프트 검사가 공유할 기계 판독 블록. 과거 점수는 수정하지 않는다. 실제 이미지·영상, 검증된 모델과 제출 자료, 전환 승인은 여전히 별도 조건이다.
