# 04 — QA와 포스트프로덕션 인계

## 1. 게이트
| 게이트 | 통과 기준 | 증거 |
|---|---|---|
| G0 인계 | 승인된 coverage_set의 필수 항목 전부가 clip/shot/panel·사건/대사·필요 소스에 빠짐없이 대응, 최초 누락/임의 선택화 없음 | 파일/버전/해시, 범위 revision, 필수 항목 추적표 |
| G1 제출 | 필수 선행 채택구간·실제 역할·참조 선택·현재 설정·실행/전송 승인 일치 | 최종 요청과 native readiness/선택, 기능/비용 관측 |
| G2 테이크 | 실제 다운로드·기술 검사와 요구별 전구간 시청/해당 청취 | 원본 hash, probe/decode, 시각·청취 관측 |
| G3 연속성 | 해당 참조·재등장·모든 요구 접합에서 유지/변화가 설계와 일치 | 정확한 take/range에 묶인 경계 재생·대조 |
| G4 전체 흐름 | 편집 순서 전체에서 정보·행동·연기/음향 흐름이 유지 | 검수용 러프 연결본 hash·순서·전구간 검사 |
| G5 인계 | coverage_set 전 항목이 실제 유효 take/range와 요구 검수로 충족, 소스·음향·조건·권리/한계 완비 | 항목별 역대조, handoff manifest 및 수령 검사 |

G3는 필요한 선행 테이크와 현재 테이크가 준비되면 부분 실행 가능하다. 미래 클립이 없다고 최초 채택을 영원히 막지 않는다. 이후 이웃이 생성되면 해당 경계 검사, 배치 종료 전에는 모든 필수 경계를 닫는다. G4 검토로 기존 채택에 결함이 발견되면 판정 revision과 영향 범위를 갱신한다.

## 2. 무엇을 보는가
- 요구 내용: 필수 사건·대사 원문/화자·공개 순서·반응 원인·의도한 연기.
- 캐릭터: 성인/신원·고유 표지·헤어·의상·손/발·시선. 보이지 않는 표지는 판정 제외 사유를 적는다.
- 에셋: 소유 손·소품 상태·장면별 버전·지리·광원·생물 수/형태.
- 운동: 시작/정점/끝뿐 아니라 전구간 속도·접촉·가림·관통·카메라와 피사체 운동.
- 음향: 실제 stream 유무·화자/목소리·발화/행동 동기·거리·환경 연속성. 권한 없는 voice clone 대체 금지.
- 기술: 실제 파일 해상도/화면비/FPS/길이/디코드·프레임 중복·음향 clipping 및 요구된 문자/로고/워터마크 부재.

이미지 접촉 시트는 검사 보조다. 재생 없이 motion PASS, 청취 없이 audio PASS를 기록하지 않는다. 실제 지각 가능한 도구가 없으면 UNVERIFIED로 차단한다. 정지 캡처 개수나 모델 설명문은 전구간 검수의 대체가 아니다. 보편적인 임의 수치 점수 대신 프로젝트별 요구·허용치와 관측 근거를 사용한다.

## 3. 판정
검사별 pass/fail/unverified/not_applicable와 이유를 기록한다.
- accepted: 해당 역할의 모든 필수 요구에 통과. 실제 생성 품질의 무오류 보장이 아니라 명시된 검수 범위의 채택.
- conditional: 필수 서사/참조 속성은 충족하되 특정 후반 처리로 해소 가능한 결함. 구간·수정 방법·가능 근거·후반 담당/수락을 명시. 얼굴 변형·접촉 부재·필수 대사 누락을 막연한 편집 가능성으로 넘기지 않는다.
- rejected: 필수 요구 위반. 정확한 타임코드/프레임·문제·영향·재작업 소유자를 반환.
- unverified: 필수 검사 능력/증거 부족. 조건부 채택으로 숨기지 않는다.

conditional 결과가 후속 생성에 쓰일 때는 해당 참조 imports에 결함이 영향을 주지 않는다는 별도 판정이 필요하다. 정식 인계 완료에는 사용자의 조건부 허용 정책과 포스트 수령자의 확인도 필요하다. 정책 미정이면 조건부는 미완료로 남긴다.

## 4. 러프 연결본의 권한과 한계
채택/검토 가능한 정확한 구간을 원래 편집 순서대로 연결한다. 후보를 포함한 검토본은 후보 상태를 기록하고 최종 납품과 구분한다. 누락 클립을 검은 화면으로 채워 전체 완료라고 하지 않는다.

검수용 렌더 권한을 확인하고, 원본을 덮어쓰지 않는다. FPS/해상도/음향 정규화가 필요하면 원본 계보와 변환 설정을 기록하며 그 변환으로 원본 품질이 좋아졌다고 주장하지 않는다. 컷 간 차이를 감추기 위한 크롭·배속·전환·음악·합성을 임의 삽입하지 않는다.

## 5. 인계
필수 파일은 원본/채택 take, source hash와 source range, 계획 shot/panel 대응, 실제 handle, source audio 상태·사용 가능 트랙, reference lineage, G2–G4 결과, 조건부 후반 작업·권리 제한이다. 없는 개별 stem을 실제 트랙처럼 인계하지 않는다.

포스트가 제안된 구간·접합을 변경하면 변경 부분의 검수를 다시 수행해야 한다. 프로덕션 인계 통과는 포스트 최종 마스터 QA를 대신하지 않는다.

## 6. 진행률
서로 다른 분모를 합치지 않는다.
- 제출: 제출 접수가 확인된 필수 clip / 전체 필수 clip. 채택률이 아님.
- 채택: 현재 fingerprint·판정 revision이 유효한 accepted clip / coverage_set에서 배정한 전체 필수 clip. conditional 별도 표시.
- 요구 충족: 실제 유효 소스구간과 검수로 충족한 필수 coverage 항목 / 전체 필수 coverage 항목. clip 채택률과 별도로 표시.
- 접합: 현재 take/range revision 기준 통과한 필수 join / 전체 필수 join.
- 전체 흐름: G4 통과 0/1 또는 1/1. 일부 재생은 완료가 아님.
- 인계: G5 완료 0/1 또는 1/1.

필수 노드 변경은 이유·승인을 기록한 batch revision으로만 분모를 바꾼다. 실패·미제출 노드를 삭제해 100%를 만들지 않는다. 조건부 정책이 승인된 경우에도 일반 채택률과 조건부 포함 인계 가능률을 나눠 표시한다. 배치 완료는 필수 coverage 전 항목과 그 소스가 허용된 정책에 따라 충족/채택되고 필수 접합/G4/G5가 모두 닫힌 경우다. pending_revalidation/stale 결과는 이를 충족하지 않는다.
